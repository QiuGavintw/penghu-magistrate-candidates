# 方法論

以各候選人選舉公報所刊登的政見文字合併為單一文檔，對每個政見進行中文字 bigram 分詞，計算 TF-IDF 向量後以 cosine similarity 計算候選人兩兩之間的整體相似度。

**來源：澎湖縣選舉委員會・選舉公報（CEC 公告）**

# 解讀

* **許智富(1) ↔ 周倪安(2) = 0.42**：兩人在公報中均未刊登正式政見條目，僅以簡短說明描述參選方向，文字高度重疊（「未列正式政見」字樣相似），故相似度偏高，不具實質政策意義。
* **葉竹林(3) ↔ 陳振中(5) = 0.22**：兩人都提出多項具體政見，在交通、漁業、觀光方向重疊度最高。
* **葉竹林(3) ↔ 吳淑瑾(4) = 0.18**：敬老照護、青年安居方向相近。
* **吳淑瑾(4) ↔ 陳振中(5) = 0.17**：醫療、交通、航空方向重疊。
* **葉竹林(3) ↔ 陳盡川(6) = 0.14**：海洋保育與漁業方向相近。
